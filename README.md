# Discover Generation CRM

Live demo-ready Sales + CRM + Fulfillment system.

## Run locally (computer)

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to make it work on iPad / phone

### Easiest free method – Vercel (recommended)

1. Create a free account at https://vercel.com
2. Create a free GitHub account if you don’t have one
3. Upload this project folder to a new GitHub repository
4. In Vercel → “Add New Project” → Import the GitHub repo
5. Click Deploy

After 1–2 minutes you will get a public link like:
https://discover-crm-xxxxx.vercel.app

Open that link on your iPad. It works fully.

### Alternative: StackBlitz (no install needed)

You can also open the project in the browser editor at stackblitz.com and get a live preview link that works on iPad.
